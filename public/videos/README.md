# public/videos/ — 움직이는 사진(이미지 투 비디오) 클립

갤러리 사진을 AI로 살짝 움직이게 만든 짧은 영상 클립을 여기에 넣습니다.
하객이 갤러리에서 사진을 탭하면, 그 사진에 연결된 이 영상이 크게 열리며
음소거로 자동 재생·반복됩니다. (영상이 없는 사진은 정지 이미지로 크게 보입니다.)

## 만드는 법
1. 외부 AI 이미지투비디오 툴에서 정지 웨딩 사진으로 짧은 모션 클립 생성
   - 예: Runway Gen-3 / Kling / Luma Dream Machine / Hailuo(MiniMax)
2. 권장 사양
   - 형식: **mp4 (H.264)**
   - 비율: 세로 **4:5** (갤러리 폴라로이드 프레임과 일치)
   - 길이: **3~5초**, 반복 시 튀지 않게(자연스러운 루프)
   - 용량: 클립당 수 MB 이내 (모바일 데이터 고려)
   - 소리: 자동재생을 위해 **음소거** 전제
3. 파일을 이 폴더(`public/videos/`)에 넣습니다. 예: `038A7199.mp4`

## 연결하는 법
- 관리자 페이지(`/admin`) → **사진 탭** → 해당 갤러리 항목의
  "움직이는 사진 영상 경로"에 `/videos/038A7199.mp4` 처럼 입력 → 저장
- 또는 `src/config/site.config.ts` 의 gallery 항목에 `video: "/videos/038A7199.mp4"` 추가
